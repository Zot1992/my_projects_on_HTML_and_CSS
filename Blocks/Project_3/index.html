HTML5

HTML5 - это пятая и последняя версия языка гипертекстовой разметки, который используется для структурирования содержимого веб-страниц

CSS3

CSS3 - это третья версия языка стилей CSS (Cascading Style Sheets), используемого для описания внешнего вида веб-страниц

JavaScript

JS - это язык программирования, который используется для создания интерактивных веб-страниц, серверной части и мобильных приложений
